Código para a micro:bit (MakeCode)
  1. No MakeCode, adicione a extensão NeoPixel. Não use Bluetooth: o editor avisa que é incompatível com NeoPixel.
  2. Troque para a aba JavaScript, cole o código abaixo e volte para Blocos.
  3. Baixe o programa na micro:bit, conecte o cabo USB e clique em Conectar por USB nesta página.
